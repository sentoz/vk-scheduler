# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog][],
а проект придерживается принципов [семантического версионирования][].

## [0.1.0][] - 2026-01-13

### Добавлено

* Добавлена поддержка непрозрачных идентификаторов Managed Kubernetes
  (Managed-k8s) с учётом регистра. Для виртуальных машин и Magnum сохранена
  проверка UUID в нижнем регистре. Небезопасные символы в URL отклоняются.
* Добавлена безопасная подсказка при ошибке HTTP 404 во время аутентификации без
  раскрытия тела ответа. Уточнён механизм явного обмена токенов с ограниченной
  областью действия (scoped token). Исключено предположение о сроке действия
  исходного токена.
* Реализовано обновление scoped token после получения HTTP 401 в режиме токенной
  аутентификации с использованием исходных учётных данных. Предусмотрены
  совместное обновление токенов, проверка области действия и срока действия, а
  также однократное повторение неудачного запроса.
* Манифесты расписаний теперь определяют тип и идентификатор ресурса, а проект и
  регион наследуются из глобальной конфигурации. Указание параметров области
  действия непосредственно в манифестах запрещено.
* Добавлено управление расписанием кластеров Managed Kubernetes: явный выбор
  сервиса, команды запуска и остановки, ожидание стабильного состояния и
  автономные контрактные и интеграционные тесты.
* Реализована первоначальная версия автономного планировщика VK Cloud для
  виртуальных машин Nova и кластеров Magnum.
* Реализован исполнитель без сохранения состояния (stateless executor) с
  объединением повторяющихся операций, транзакционной перезагрузкой расписаний и
  календарным веб-интерфейсом.
* Добавлены автономные контрактные тесты API и интеграционные тесты приложения.
  Проверка работоспособности в реальной среде (live smoke test) пока не
  выполнена.
